# Vector 9 Slice / 矢量九宫格

把一份矢量原稿做成可拉伸的九宫格：9 个带方向名称的 Frame 开启 **Clip content（裁切内容）**，每格内保留一份完整、可编辑的原稿副本。

四角固定，四边单向拉伸，中心双向拉伸。原稿保留，新结果生成在同一页面的空处。关闭插件后，拉伸规则依然有效。

## 安装

无需安装依赖，也无需运行构建命令。

1. 打开 **Figma Desktop**，进入一个 Design 文件。
2. 选择 **Plugins → Development → Import plugin from manifest…**。
3. 选择本目录的 `manifest.json`。
4. 从 **Plugins → Development → Vector 9 Slice / 矢量九宫格** 运行。

如果使用 ZIP，请先完整解压，再导入里面的 `manifest.json`。`code.js`、`ui.html` 和清单文件应保持在同一目录。

## 使用

1. 选择一个矢量、编组或普通 Frame。多层原稿先整理进一个组或 Frame。
2. 拖动预览中的四条切线，或输入上、右、下、左边距。四个角落应包含所有不希望变形的装饰。
3. 切到「拉伸预览」检查效果；这里的宽高只改变预览。
4. 点击「生成 9 个 Frame」。结果初始宽高与原稿相同，并自动选中。
5. 修改最外层 Frame 的 **W / H** 或拖动其边界，四角会保持原尺寸。请使用普通调整尺寸操作；Figma 的 **K 缩放工具**会把四角也一起缩放。

切线可使用方向键移动，每次 1 px；按住 Shift 每次 10 px。「恢复均分」将四条切线恢复到三等分的位置。

例如，26 × 26 的底板可以把上、右、下、左均设为 **11 px**，得到 11 / 4 / 11 的九宫格。

## 生成的图层

```text
原稿名_9slice
├── 透明矩形
├── ↖️·左上
├── ⬆️·上
├── ↗️·右上
├── ⬅️·左
├── ↔️↕️·中心
├── ➡️·右
├── ↙️·左下
├── ⬇️·下
└── ↘️·右下
```

「透明矩形」位于外层 Frame 的直属子层最上方，起点为 (0, 0)，宽高与外框一致，纯色填充不透明度为 100%、Appearance 中的图层不透明度为 0%、无描边，并以水平和垂直 Stretch 约束随外框同步拉伸。

每个方向 Frame 的内部结构：

```text
↖️·左上                ← 开启 Clip content 的可见窗口
└── 原稿名              ← 原始 Vector / Group / Frame 的完整副本
```

方向 Frame 直接包含原稿副本，不增加中间的「原稿」Frame。不会合并路径，也不会把原稿转换为图片。面板里的 PNG 仅供预览，不参与生成。

| 区域 | 相对外层 Frame 的水平约束 | 垂直约束 |
| --- | --- | --- |
| 左上 | Left，固定到左侧 | Top，固定到顶部 |
| 上 | Left & Right，横向延展 | Top |
| 右上 | Right | Top |
| 左 | Left | Top & Bottom，纵向延展 |
| 中心 | Left & Right | Top & Bottom |
| 右 | Right | Top & Bottom |
| 左下 | Left | Bottom |
| 下 | Left & Right | Bottom |
| 右下 | Right | Bottom |

内部原稿在需要拉伸的轴上设置 **Scale（按比例调整该轴）**，并同步配置副本后代的约束，保证裁切区域随窗口一起延展。

## 编辑与边界

- 九个原稿副本彼此独立，原稿修改后不会自动同步。重新读取并生成会创建一份新结果；已有结果保留。
- 选中之前生成的结果并重新打开插件，可找回它的原稿和生成时的边距。原稿被移除时，会提示重新选择。
- 首版支持普通 Frame、Group、Vector、基础形状和布尔运算。原稿最多 2,000 个图层。
- 对文字、自动布局、组件/实例、旋转或翻转图层，插件会提示先在原稿副本中整理：文字转轮廓、分离实例或转成普通 Frame、移除自动布局。不会代替用户自动改变这些结构。
- 每条边距及中心区域宽高至少为 0.01 px。手动缩小结果时，外层宽高仍须大于左右、上下固定边距之和，避免固定角落相互重叠。
- 真实 Figma API 的小数宽高测试出现了原生约束的像素取整。建议按整像素增减外层宽高；典型整数尺寸已验证无缝。小数边距本身可以保留。
- 蒙版请连同它控制的内容一起选中所在组。超出原稿尺寸的阴影等内容会受裁切窗口限制。
- 全部本地处理，插件不访问网络。

## 开发与验证

插件运行不需要 Node.js。开发检查需要 Node.js 20 或更新版本，无需安装第三方依赖：

```sh
npm run check
```

检查包含 JavaScript 语法和 10 项测试，覆盖九宫格分区、约束、非法参数、原稿删除以及预览和页面切换时的状态处理。

v1.0.2 已通过真实 Figma Plugin API 验证：Frame、Group、Vector 和布尔图形直接放入方向 Frame 后，在 100 × 80 → 160 × 120 → 100 × 80 的过程中，位置、尺寸及后代拉伸均正确；方向命名和透明矩形属性也通过检查。浏览器中已验证预览、切线键盘操作、防重复提交和错误状态。这些检查分别验证图层算法与插件界面，桌面端整包导入仍需实际验收。
